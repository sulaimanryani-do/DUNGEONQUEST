# 🛡️ DungeonQuest - Java Console Game

Un projecte de joc d'aventures i mascares (Dungeon Crawler) desenvolupat en **Java**, orientat a la lògica de programació i a l'aplicació de principis de **Programació Orientada a Objectes (POO)**.

## 🚀 Tecnologies i Eines
* **Llenguatge:** Java
* **Entorn de Desenvolupament (IDE):** Eclipse
* **Control de Versions:** Git / GitHub

## 📂 Estructura del Projecte
El codi font està organitzat seguint l'estàndard d'Eclipse:

│
└── README.md

## 🛠️ Característiques Principals
* Gestió de diferents tipus de sales (trampes, combats, tresors).
* Sistema de combat i interacció entre el personatge i els monstres.
* Aplicació de conceptes avançats de POO (herència, polimorfisme i encapsulament).
